# Bank-churn-prediction
A Machine Learning application built using Flask and Random Forest to proactively identify banking customers at risk of churn
# Project Overview
In an increasingly competitive banking sector, retaining customers is vital. This project introduces an end-to-end Machine Learning pipeline that analyzes historical client indicators such as credit scores, geographical location, age, tenure, balance, and account activity—to proactively flag individuals at high risk of exiting the bank.
